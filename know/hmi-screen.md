# 陶晶驰 USART HMI 串口屏设计包

本文档用于在陶晶驰 320x240 串口屏和 USART HMI 软件中重建本项目的 LCD 界面。当前 STM32 端已经按本文的控件名、页面号和协议解析数据，制作 `.HMI` 工程时应严格保持命名一致。

## 1. 屏幕与通信

- 屏幕：陶晶驰 USART HMI，320x240。
- 连接：STM32 UART4，PC10/PC11，9600 bps。
- STM32 写 HMI：标准文本命令，结尾 `FF FF FF`，例如 `t0.txt="26.5"`。
- HMI 写 STM32：二进制帧，帧头 `55 AA`，帧尾 `0D 0A`。
- HMI 只发送用户动作和页面进入事件；真实状态以 STM32 回写为准。
- 9600 bps 下不要做高频动画；滑块拖动只改本页显示，弹起时再发串口。

## 2. 总体 UI 风格

- 页面数量固定为 3 页：`page0` 环境总览、`page1` 灯光控制、`page2` 风扇控制。
- 只显示可用设备：室内灯 ID=1、室外灯 ID=3、风扇。不要显示未开放或已保留通道。
- 顶部 0-28 px：标题、WiFi/自动/告警状态。
- 内容区 28-204 px：传感器卡片或控制区。
- 底部 204-240 px：三个导航按钮。
- 配色建议：深色背景、青蓝色表示正常/选中、红色表示异常、灰色表示离线或禁用。
- 数值用大字号右对齐，单位用小字号；图标使用 HMI 图片资源，不直接发送 Emoji 字符。

## 4. STM32 回写控件清单

这些控件可以在多个页面都放置同名控件；不需要显示的页面可以隐藏。STM32 会按当前页面和变化检测回写。

| 控件名 | 类型 | 页面 | STM32 写入内容 |
|---|---|---|---|
| `t0` | 文本 | page0/page2 | 温度，示例 `26.5`，无效为 `--` |
| `t1` | 文本 | page0 | 湿度，示例 `56.0`，无效为 `--` |
| `t2` | 文本 | page0 | PM2.5，示例 `35.2`，无效为 `--` |
| `t12` | 文本 | page0 | MQ2 烟雾 ppm，示例 `120.0`，无效为 `--` |
| `t13` | 文本 | page0/page1 | 光照 lux，示例 `180`，无效为 `--` |
| `t14` | 文本 | page0 | 任一可用灯带是否开启：`开`/`关` |
| `t15` | 文本 | page1 | 当前选中灯带状态：`开`/`关` |
| `t16` | 文本 | page0/page2 | 人脸状态：`已识别`/`在线`/`离线` |
| `t17` | 文本 | page0 | ESP32 状态：`在线`/`离线` |
| `t18` | 文本 | page0 | 空气/传感器状态：`预热中`/`异常`/`正常` |
| `t19` | 文本 | page0/page1 | 自动化状态：`AUTO`/`MANUAL` |
| `t20` | 文本 | page2 | 风扇模式：`AUTO`/`MANUAL`/`STOP` |
| `h0` | 滑块 | page1/page2 | page1=R 值 0-255；page2=风扇 PWM 0-1000 |
| `h1` | 滑块 | page1 | G 值 0-255 |
| `h2` | 滑块 | page1 | B 值 0-255 |
| `n0` | 数字 | page1/page2 | page1=R 值；page2=风扇 PWM |
| `n1` | 数字 | page1 | G 值 |
| `n2` | 数字 | page1 | B 值 |
| `h_cur` | 滑块/数值，隐藏 | page1 | 当前灯带 ID，只允许 1 或 3 |
| `b13` | 按钮 | page1 | 灯光开关文本：`开`/`关` |
| `b7` | 按钮 | page2 | 风扇开关文本：`开`/`关` |
| `sys0` | 系统变量 | page1 | STM32 同步灯光控件后置 0 |
| `sys1` | 系统变量 | page2 | STM32 同步风扇控件后置 0 |

## 5. page0：环境总览

### 推荐布局

| 区域 | 控件 | 内容 |
|---|---|---|
| 顶部 | 标题文本 | `环境总览` |
| 顶部右侧 | `t17` | ESP32 `在线/离线` |
| 第一行左 | `t0` + 单位 | 温度 `℃` |
| 第一行右 | `t1` + 单位 | 湿度 `%` |
| 第二行左 | `t2` + 单位 | PM2.5 `ug/m3` |
| 第二行右 | `t12` + 单位 | 烟雾 `ppm` |
| 第三行左 | `t13` + 单位 | 光照 `lux` |
| 第三行右 | `t18` | `预热中/异常/正常` |
| 底部状态 | `t14` `t16` `t19` | 灯光、人脸、自动化 |

### page0 初始化事件

在 `page0` 的页面初始化事件中写：

```text
printh 55 AA 01 00 0D 0A
```

### page1 初始化事件

```text
h_cur.val=1
printh 55 AA 01 01 0D 0A
printh 55 AA 07 01 0D 0A
```

### 选择室内灯：`b_led1` 弹起事件

```text
h_cur.val=1
printh 55 AA 07
printh 01
printh 0D 0A
```

### 选择室外灯：`b_led3` 弹起事件

```text
h_cur.val=3
printh 55 AA 07
printh 03
printh 0D 0A
```

### RGB 滑块拖动事件

分别放到 `h0`、`h1`、`h2` 的滑动事件中。拖动时不要发串口，只更新本地显示，降低 UART4 压力。

```text
n0.val=h0.val
n1.val=h1.val
n2.val=h2.val
if(h0.val>0)
{
  b13.txt="开"
}
if(h1.val>0)
{
  b13.txt="开"
}
if(h2.val>0)
{
  b13.txt="开"
}
if(h0.val==0)
{
  if(h1.val==0)
  {
    if(h2.val==0)
    {
      b13.txt="关"
    }
  }
}
```

### RGB 滑块弹起事件

分别放到 `h0`、`h1`、`h2` 的弹起事件中。

```text
n0.val=h0.val
n1.val=h1.val
n2.val=h2.val
printh 55 AA 04
prints h_cur.val,1
prints h0.val,1
prints h1.val,1
prints h2.val,1
printh 0D 0A
```

### 灯光开关：`b13` 弹起事件

```text
if(b13.txt=="开")
{
  b13.txt="关"
  h0.val=0
  h1.val=0
  h2.val=0
  n0.val=0
  n1.val=0
  n2.val=0
}
else
{
  b13.txt="开"
  h0.val=125
  h1.val=125
  h2.val=125
  n0.val=125
  n1.val=125
  n2.val=125
}
printh 55 AA 04
prints h_cur.val,1
prints h0.val,1
prints h1.val,1
prints h2.val,1
printh 0D 0A
```

### 预设按钮脚本

预设按钮都使用同一模板，只替换 RGB 值。

```text
b13.txt="开"
h0.val=255
h1.val=255
h2.val=255
n0.val=h0.val
n1.val=h1.val
n2.val=h2.val
printh 55 AA 04
prints h_cur.val,1
prints h0.val,1
prints h1.val,1
prints h2.val,1
printh 0D 0A
```

| 按钮 | 名称 | R | G | B |
|---|---|---:|---:|---:|
| `b3` | 白光 | 255 | 255 | 255 |
| `b4` | 暖光 | 255 | 200 | 100 |
| `b5` | 夜灯 | 12 | 10 | 5 |
| `b6` | 阅读 | 178 | 140 | 70 |
| `b8` | 红色 | 255 | 0 | 0 |
| `b9` | 绿色 | 0 | 255 | 0 |

## 7. page2：风扇控制

### 控件清单

| 控件名 | 类型 | 属性建议 | 用途 |
|---|---|---|---|
| `h0` | 滑块 | 范围 0-1000 | 风扇 PWM |
| `n0` | 数字 | 范围 0-1000 | 风扇 PWM 显示 |
| `b7` | 按钮 | 文本 `开/关` | 风扇开关 |
| `t20` | 文本 | 只读 | `AUTO/MANUAL/STOP` |
| `t0` | 文本 | 只读 | 当前温度，可选 |
| `t16` | 文本 | 只读 | 人脸状态，可选 |
| `b_auto` | 按钮 | 文本 `自动` | 风扇自动模式 |
| `b_manual` | 按钮 | 文本 `手动` | 风扇手动模式 |
| `b_stop` | 按钮 | 文本 `停止` | 风扇停止模式 |
| `n_hi` | 数字 | 隐藏 | PWM 高字节 |
| `n_lo` | 数字 | 隐藏 | PWM 低字节 |

### page2 初始化事件

```text
printh 55 AA 01 02 0D 0A
printh 55 AA 08 0D 0A
```

### 风扇滑块拖动事件：`h0`

```text
n0.val=h0.val
if(h0.val==0)
{
  b7.txt="关"
}
else
{
  b7.txt="开"
}
```

### 风扇滑块弹起事件：`h0`

```text
n0.val=h0.val
n_hi.val=h0.val/256
n_lo.val=h0.val-n_hi.val*256
printh 55 AA 05
prints n_hi.val,1
prints n_lo.val,1
printh 0D 0A
```

### 风扇开关：`b7` 弹起事件

```text
if(b7.txt=="开")
{
  b7.txt="关"
  h0.val=0
  n0.val=0
}
else
{
  b7.txt="开"
  h0.val=500
  n0.val=500
}
n_hi.val=h0.val/256
n_lo.val=h0.val-n_hi.val*256
printh 55 AA 05
prints n_hi.val,1
prints n_lo.val,1
printh 0D 0A
```

### 风扇模式按钮

`b_auto` 弹起事件：

```text
printh 55 AA 09 02 0D 0A
```

`b_manual` 弹起事件：

```text
printh 55 AA 09 01 0D 0A
```

`b_stop` 弹起事件：

```text
printh 55 AA 09 00 0D 0A
```

## 9. HMI 到 STM32 协议

| 功能 | 帧格式 | 说明 |
|---|---|---|
| 页面进入 | `55 AA 01 <page_id> 0D 0A` | `page_id`: 0/1/2 |
| 设置灯光 | `55 AA 04 <strip_id> R G B 0D 0A` | `strip_id`: 1=室内灯，3=室外灯 |
| 设置风扇速度 | `55 AA 05 <high> <low> 0D 0A` | PWM 0-1000，大端高低字节 |
| 查询灯光 | `55 AA 07 <strip_id> 0D 0A` | 进入 page1 或切换灯带后调用 |
| 查询风扇 | `55 AA 08 0D 0A` | 进入 page2 后调用 |
| 设置风扇模式 | `55 AA 09 <mode> 0D 0A` | `0`=停止，`1`=手动，`2`=自动 |

注意：OneNET 中红色字段名沿用现有 `RGB1_RAD`/`RGB3_RAD`，但 HMI 串口协议里就是普通的 R/G/B 三个字节。

## 10. 字库规划

不建议做完整 Unicode 字库，STM32 端和 HMI 动态文本只需要白名单。Emoji 不作为 UTF-8 文本发送，应转成 HMI 图片资源。

| 字库文件 | 字号 | 字符白名单 |
|---|---:|---|
| `val.zi` | 16 px | `0123456789.-%℃ABCDEFGHIJKLMNOPQRSTUVWXYZ/ ` |
| `数据.zi` | 16 px | `开关在线离线已识别预热中异常正常温度湿度光照烟雾灯光风扇自动手动停止室内室外智能家居警告` |
| `数字24.zi` | 24 px | `0123456789.-` |
| `副标题.zi` | 32 px | `环境总览灯光控制风扇控制室内灯室外灯` |
| `标题.zi` | 40 px | `智能家居警告` |

如果静态中文标题和标签全部做成图片，初版只需要动态文本字库：`val.zi` 和 `数据.zi`。

## 12. USART HMI 制作检查表

- 三页名称必须是 `page0`、`page1`、`page2`。
- 不创建可点击的未开放或已保留通道入口。
- `page1` 的 `h_cur` 默认值为 1，只允许按钮写入 1 或 3。
- `page2` 的 `h0` 范围是 0-1000，不是 0-100。
- 所有 HMI 到 STM32 的帧必须以 `0D 0A` 结束。
- STM32 到 HMI 的命令由固件自动追加 `FF FF FF`，HMI 工程内不需要处理。
- 如果屏幕支持 `bkcmd`，建议启动页设置 `bkcmd=0`，减少串口回包干扰。
- 先测试页面进入和查询，再测试控制：进入 page1 后应收到当前灯值；进入 page2 后应收到当前风扇 PWM。
- 滑块只在弹起事件发控制帧，不要在滑动事件持续发送。
