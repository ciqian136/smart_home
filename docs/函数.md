# 对外暴露函数说明

本文整理当前 `APP/` 模块头文件中对外暴露的函数。这里的“对外暴露”指声明在 `APP/*.h` 中、可被其他模块调用的函数；`static` 内部函数、STM32 HAL / CubeMX 生成函数不在本文范围内。

## 调度与系统辅助

### `schedule.h`

| 函数 | 作用 |
| --- | --- |
| `void schedule_init(void)` | 初始化应用任务调度表，计算当前任务数量，通常在主程序初始化阶段调用。 |
| `void schedule_run(void)` | 周期运行任务调度器，按任务间隔调用各模块 `*_proc` / `*_run` 函数，同时维护 UART 发送队列。 |

### `board_led.h`

| 函数 | 作用 |
| --- | --- |
| `void board_led_set(uint8_t on)` | 设置板载 LED 状态，`on != 0` 点亮，`on == 0` 熄灭。 |
| `void board_led_on(void)` | 点亮板载 LED。 |
| `void board_led_off(void)` | 熄灭板载 LED。 |
| `void board_led_toggle(void)` | 翻转板载 LED 状态，常用于调试确认命令是否收到。 |
| `uint8_t board_led_is_on(void)` | 返回板载 LED 当前逻辑状态，`1` 表示点亮，`0` 表示熄灭。 |

## 通用底层模块

### `my_uart.h`

| 函数 | 作用 |
| --- | --- |
| `void my_uart_init(void)` | 初始化 USART1/2/3、UART4/5 的接收队列、发送队列，并启动 ReceiveToIdle 中断接收。 |
| `void uart_printf(UART_HandleTypeDef *huart, const char *format, ...)` | 通用格式化发送接口，数据写入对应 UART TX 环形队列，由中断发送，不直接阻塞等待发送完成。 |
| `uint16_t my_uart_write(UART_HandleTypeDef *huart, const uint8_t *data, uint16_t len)` | 向指定 UART 的 TX 环形队列写入原始字节，返回实际写入长度。 |
| `uint16_t my_uart_tx_pending(UART_HandleTypeDef *huart)` | 查询指定 UART 当前等待发送的字节数。 |
| `uint16_t my_uart_tx_free(UART_HandleTypeDef *huart)` | 查询指定 UART TX 队列剩余可写空间。 |
| `uint32_t my_uart_get_tx_overflow(UART_HandleTypeDef *huart)` | 查询指定 UART TX 队列溢出计数，用于判断发送是否过快或队列是否太小。 |
| `void my_uart_service_tx(void)` | 轮询推进各 UART 的中断发送状态，调度循环中需要高频调用。 |
| `uint16_t my_uart_available(UART_HandleTypeDef *huart)` | 查询指定 UART RX 队列中当前可读字节数。 |
| `uint16_t my_uart_read(UART_HandleTypeDef *huart, uint8_t *dst, uint16_t capacity)` | 从指定 UART RX 队列读取最多 `capacity` 字节到 `dst`，返回实际读取长度。 |
| `uint16_t my_uart_read_line(UART_HandleTypeDef *huart, char *dst, uint16_t capacity)` | 从指定 UART RX 队列读取一行文本，主要用于 ASRPRO / OpenART 这类换行协议。 |
| `void my_uart_clear_rx(UART_HandleTypeDef *huart)` | 清空指定 UART RX 队列。 |
| `uint32_t my_uart_get_rx_overflow(UART_HandleTypeDef *huart)` | 查询指定 UART RX 队列溢出计数，用于判断接收是否丢包。 |

### `ring_queue.h`

| 函数 | 作用 |
| --- | --- |
| `void ring_queue_init(ring_queue_t *queue, uint8_t *buffer, uint16_t size)` | 使用外部静态缓冲区初始化环形队列。 |
| `void ring_queue_clear(ring_queue_t *queue)` | 清空环形队列读写位置和溢出状态。 |
| `uint8_t ring_queue_push(ring_queue_t *queue, uint8_t data)` | 写入单字节，成功返回 `1`，队列满返回 `0` 并记录溢出。 |
| `uint16_t ring_queue_write(ring_queue_t *queue, const uint8_t *data, uint16_t len)` | 批量写入字节，返回实际写入数量。 |
| `uint8_t ring_queue_pop(ring_queue_t *queue, uint8_t *data)` | 弹出单字节，成功返回 `1`，队列空返回 `0`。 |
| `uint16_t ring_queue_read(ring_queue_t *queue, uint8_t *data, uint16_t len)` | 批量读取并移除字节，返回实际读取数量。 |
| `uint16_t ring_queue_drop(ring_queue_t *queue, uint16_t len)` | 丢弃指定数量字节，常用于 UART TX 中断发送完成后释放队列数据。 |
| `uint8_t ring_queue_peek_at(const ring_queue_t *queue, uint16_t offset, uint8_t *data)` | 不移除数据，读取队列中指定偏移位置的字节。 |
| `uint16_t ring_queue_available(const ring_queue_t *queue)` | 返回队列当前已有数据量。 |
| `uint16_t ring_queue_free(const ring_queue_t *queue)` | 返回队列剩余空间。 |
| `uint32_t ring_queue_overflow(const ring_queue_t *queue)` | 返回队列累计溢出次数。 |

### `my_adc.h`

| 函数 | 作用 |
| --- | --- |
| `void my_adc_init(void)` | 初始化用户 ADC 状态并执行校准。 |
| `uint16_t my_adc_read_channel(uint32_t channel)` | 同步读取指定 ADC 通道，切换通道后自动丢弃首个样本，当前用于烟雾 PA1 和 PM2.5 PA4。 |

## 传感器模块

### `smoke.h`

| 函数 | 作用 |
| --- | --- |
| `void smoke_init(void)` | 初始化烟雾传感器状态并开始预热计时。 |
| `void smoke_proc(void)` | 周期采样烟雾 AO 的 ADC 值，并结合 DO 输入和阈值更新报警状态。 |
| `void smoke_deinit(void)` | 反初始化烟雾模块状态，清除就绪和报警标志。 |
| `uint16_t smoke_get_adc(void)` | 获取最近一次烟雾 ADC 原始值。 |
| `uint8_t smoke_is_alarmed(void)` | 获取烟雾报警状态，`1` 表示报警，`0` 表示正常。 |
| `uint8_t smoke_is_ready(void)` | 判断烟雾模块是否完成预热，`1` 表示可使用当前读数。 |

### `PM25.h`

| 函数 | 作用 |

| `void PM25_proc(void)` | 周期控制采样 LED 脉冲并读取 PM2.5 ADC 原始值。 |
| `uint16_t PM25_get_adc(void)` | 获取最近一次 PM2.5 ADC 原始值。 |

### `dht11.h`

| 函数 | 作用 |
| --- | --- |
| `void DHT11_init(void)` | 初始化 DHT11 单总线 GPIO 和内部状态。 |
| `uint8_t DHT11_ReadData(float *temp, float *humi)` | 非阻塞读取一次 DHT11 数据；可能返回 `DHT11_READ_OK`、`DHT11_READ_ERROR` 或 `DHT11_READ_BUSY`。 |
| `void DHT11_proc(void)` | 周期驱动 DHT11 读取状态机，成功后更新模块内部温湿度缓存。 |
| `float DHT11_get_temp(void)` | 获取最近一次温度值。 |
| `float DHT11_get_humi(void)` | 获取最近一次湿度值。 |

### `BH1750.h`

| 函数 | 作用 |

| `void bh1750_proc(void)` | 周期读取 BH1750 光照值，异常时通过非阻塞状态恢复 I2C / 重新发起测量。 |

## 交互与通信模块

### `lcd.h`

| 函数 | 作用 |
| --- | --- |
| `void lcd_recv(void)` | 周期读取 UART4 接收队列，解析 USART HMI 的 RGB、风扇和查询控制帧。 |
| `void lcd_send(void)` | 将当前温度、湿度、PM2.5 ADC、烟雾 ADC、光照和灯带状态写回 HMI 控件。 |

### `voice.h`

| 函数 | 作用 |
| --- | --- |
| `void voice_run_send(void)` | 语音模块周期任务，解析 ASRPRO 命令并按优先级处理报警、人脸等后台播报。 |
| `void voice_parse(void)` | 从 UART3 读取并解析 ASRPRO 文本命令，执行灯带、风扇、LED 和环境查询动作。 |
| `void voice_alert_smoke_over_limit(uint16_t adc)` | 向 ASRPRO 发送烟雾数值过高的语音播报序列。 |
| `void voice_alert_dust_over_limit(uint16_t adc)` | 向 ASRPRO 发送粉尘数值过高的语音播报序列。 |
| `void voice_play_face_zeng(void)` | 设置人脸识别播报请求，由 `voice_run_send()` 在合适时机发送到 ASRPRO。 |

### `face.h`

| 函数 | 作用 |
| --- | --- |
| `void face_init(void)` | 初始化 OpenART 人脸识别模块的 STM32 侧状态。 |
| `void face_proc(void)` | 周期读取 UART5 文本结果，解析 `FACE:ZENG` / `FACE:NONE` / `FACE:ERR` 并更新识别状态。 |
| `uint8_t face_is_zeng_detected(void)` | 返回当前是否确认识别到 `zeng`。 |
| `uint8_t face_take_zeng_detected_event(void)` | 读取并清除一次 `zeng` 识别成功事件，适合事件式处理。 |
| `uint8_t face_get_online(void)` | 返回 OpenART 最近是否有有效通信，超时会认为离线。 |
| `uint8_t face_get_score(void)` | 返回最近一次 `zeng` 识别置信度分数。 |

### `esp32.h`

| 函数 | 作用 |
| --- | --- |
| `void esp32_init(void)` | 阻塞式 ESP32 初始化，执行 WiFi 连接、MQTT 配置和主题订阅；当前主要保留为兼容接口。 |
| `void esp32_init_nonblock(void)` | 非阻塞 ESP32 初始化状态机，调度中周期调用，完成后置位 `esp32_initialized`。 |
| `void esp32_check_cmd_timeout(void)` | 检查 AT 指令超时，避免 `at_cmd_busy` 长时间卡住。 |
| `void esp32_flush_reply(void)` | 发送待回复的 OneNET `set_reply`，用于及时确认云端下发控制。 |
| `void esp32_check_online(void)` | 维护 ESP32 在线状态，执行 MQTT PING、WiFi 检测和必要的重连处理。 |
| `void esp32_run_send(void)` | 分时构建并发送 OneNET 属性上报，包含传感器、风扇、灯带和 LED 状态。 |
| `void esp32_run_recv(void)` | 处理 USART2 接收缓存中的 AT 响应和 OneNET 云端下发控制。 |
| `void build_onenet_cmd(char *outbuf, const char *topic, const char *msg_id, uint8_t param_count, ...)` | 根据属性名、类型和值构建 OneNET `AT+MQTTPUB` 上报命令。 |
| `int8_t send_cmd_wait_resp_it(UART_HandleTypeDef *huart, char *cmd, char *expected_resp, uint32_t time_out_ms, uint8_t max_retries)` | 阻塞式发送 AT 指令并等待指定响应，带超时和重试机制。 |
| `void MQTT_Handle(char *subrecv_start)` | 解析 OneNET `+MQTTSUBRECV` 消息，处理属性上报响应和云端属性下发。 |
| `void TIME_Handle(char *timerecv_start)` | 处理 ESP32 时间相关返回内容，保留给联网时间解析路径。 |

### `json_parser.h`

| 函数 | 作用 |
| --- | --- |
| `uint8_t parse_onenet_params(const char *json, uint8_t param_count, uint8_t *found, ...)` | 从 OneNET 属性 JSON 中按参数名批量解析整数、浮点、布尔或字符串值。 |
| `uint8_t json_get_msg_id(const char *json, char *msg_id, uint8_t size)` | 从 JSON 中提取消息 `id`，用于回复 OneNET `set_reply`。 |
| `MqttMsgType_t get_msg_type(const char *topic)` | 根据 MQTT topic 判断消息类型，如属性上报回复、属性设置、设置回复等。 |
| `void extract_topic(const char *subrecv, char *topic, uint8_t size)` | 从 `+MQTTSUBRECV` 原始消息中提取 topic。 |
| `void extract_json(const char *subrecv, char *json_buf, uint16_t size)` | 从 `+MQTTSUBRECV` 原始消息中提取 JSON 负载。 |

## 说明

- `APP/headfile.h` 主要用于集中包含头文件，不定义对外函数。
- `asrpro_code.cpp` 和 `openart.py` 是辅助模块代码，不属于 STM32 `APP/*.h` 对外函数列表；它们的通信格式见 `docs/通信.md`。
- 若后续新增模块，优先在对应 `.h` 文件中声明对外接口，并同步补充到本文档。
